# Final Project ITI - AutoITI Vue.js Platform

مشروع تطبيق منصة السيارات (AutoITI) المبني بـ **Vue.js 3** و **Vite** للمشروع النهائي لـ ITI.

## التثبيت والتشغيل المحلي

1. افتح التيرمنال داخل هذا المجلد:
```bash
cd "final project iti"
```

2. قم بتثبيت الحزم (npm packages):
```bash
npm install
```

3. قم بتشغيل خادم التطوير (Dev Server):
```bash
npm run dev
```

4. لبناء النسخة الإنتاجية (Production Build):
```bash
npm run build
```
